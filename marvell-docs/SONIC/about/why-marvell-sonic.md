# Why Prestera SONiC

**Vision:** Establish Marvell as the leading open-source Campus SONiC
provider through production-hardened community SONiC and differentiated
enterprise campus solutions that partners can build on.

## Why

- **Quality gap** – SONiC release branches get updated frequently (often on
  a daily basis), which poses challenges to stabilizing code on a platform.
- **Feature gap** – Key enterprise campus features are missing today.
  Moreover, today SONiC is largely datacenter-centric, with limited
  production-ready campus features.
- **Market demand** – ODMs, OEMs, and telcos are actively seeking Campus
  SONiC ecosystem partners to collaborate with.

## What

- **Stable base commit** – Prestera SONiC sticks to a **single git commit**
  for each release where the Prestera SONiC test suite passes. Once
  released, that base commit never changes. Bug fixes and new features are
  allowed on a released version, with the restriction that the base commit
  cannot change. Every Prestera SONiC release corresponds to an upstream
  stable branch and commit.
- **Deliver production-grade, hardened community SONiC** — 100% PTF test
  pass on Marvell Prestera platforms.
- **New Enterprise features** are developed in Marvell repos and
  subsequently planned for upstream SONiC master.
- **Build an open ecosystem** that enables partners to build and
  collaborate.

## Advantages

- **Time to market** – Prestera SONiC lets partners and customers ship new
  features to their end users faster than waiting for the upstream SONiC
  release cycle.
- **Hardened Prestera SONiC** – Production-grade releases validated on
  Marvell Prestera platforms.
- **Marvell's ecosystem** – Enables partners and customers to build
  differentiated SONiC solutions on Marvell's Prestera platforms.

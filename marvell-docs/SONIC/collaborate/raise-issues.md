# Raise Issues

To report a bug or request a feature for Prestera SONiC, you can file an issue
on GitHub or contact Marvell directly.

## GitHub Issues

Open an issue in the relevant Marvell repository — typically
[marvell-sonic-buildimage](https://github.com/MarvellEmbeddedProcessors/marvell-sonic-buildimage/issues)
for build, deployment, or platform problems, or the Marvell submodule
repository that owns the component you are working with. See [Prestera SONiC
Repos](../developers/know-marvell-sonic-repositories.md#prestera-sonic-repos) for
the list of Marvell repositories.

For steps on creating and filling out a GitHub issue, see the GitHub
documentation: [Creating an
issue](https://docs.github.com/en/issues/tracking-your-work-with-issues/using-issues/creating-an-issue).

Include a clear description of the problem, steps to reproduce it, what you
expected to happen, what actually happened, and any relevant logs or
configuration details.

## Contact Marvell

Alternatively, reach out to the **Marvell sales team** for support or to
escalate an issue.
